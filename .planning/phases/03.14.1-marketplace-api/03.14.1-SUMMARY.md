Skill Marketplace service — extends (does **NOT** replace, per D-41)

## Deviations from Plan

### Auto-fixed Issues (security review round-2 @ `84433535`)

- **Found-during**: the v3.14.1 backend shipped with 3 vulnerabilities
  surfaced by the round-2 audit:
  1. **CRITICAL: Spoofed `author_principal`** — the marketplace allowed
     a caller to pass any `author_principal` in the `submit_skill` body,
     bypassing the authenticated identity.
  2. **HIGH: Role-prefix bypass** — the marketplace accepted role
     strings that included prefix characters (e.g. `"reviewer\n"`,
     `"admin "`), allowing ACL bypass via input validation gaps.
  3. **HIGH: Unassigned reviewer promotion** — a caller with no
     reviewer assignment could advance a DRAFT → REVIEW, bypassing the
     marketplace's reviewer requirement.
- **Issue**: the round-2 fix had to (a) make `actor_role` REQUIRED on
  `promote_skill()` (was previously optional with silent fall-back to
  `Public`); (b) sanitize role inputs via the `OwnerRole` enum; (c)
  enforce the reviewer assignment via the principal-roles map.
- **Fix**: `AuthenticatedPrincipal` now carries `role: OwnerRole`
  (field added in `ecosystem.py:106`); marketplace routes consume
  `principal.role` and pass it into `actor_role=`. 3 new regression
  tests locked the behavior.
- **Files modified**: `tools/eaasp-ecosystem/src/eaasp_ecosystem/ecosystem.py`
  (+4 lines — `AuthenticatedPrincipal.role` field), `marketplace.py`
  (+147 lines — `actor_role` enforcement + reviewer assignment), `test_marketplace.py`
  (+188 lines — 3 new regression tests).
- **Commit**: `84433535 fix(03.14.x): round-2 security review — author_principal + role + reviewer`.

## Decisions

- **D-41 "extends, does not replace"** — `SkillMarketplace.submit_skill`
  makes an HTTP call to `EAASP_SKILL_REGISTRY_URL/skills/draft` and
  delegates the manifest storage to v3.11.2. The marketplace projection
  tables (`skill_lifecycle` + `skill_acl`) are additive only.
- **4-stage promotion with `VALID_TRANSITIONS` dict** — deterministic
  state machine: `draft → review → certified → published`; reverse
  transitions rejected with `MarketplacePromotionError`.
- **`actor_role` REQUIRED on `promote_skill`** (per round-2 fix) —
  prevents silent role fall-back; ACL enforced via the
  `principal-roles` map (`cfg.principal_roles` + env var).
- **`MarketplaceStats` derives from existing L3 / L4 rows** — no new
  analytics table. The histogram is computed via SQL `GROUP BY`.
