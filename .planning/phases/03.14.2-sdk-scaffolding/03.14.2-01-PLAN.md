# Phase 03.14.2 Plan — SDK scaffolding + JSON-schema exposition

## Objective

Ship the v3.14.2 SDK scaffolding: a thin-client `EaaspEcosystemClient`
(sync + async) wrapping the 10 L4 `/v1/ecosystem/*` endpoints, a
MARKETPLACE-03 CLI subcommand set added to the existing
`eaasp-ecosystem` argparse CLI, and a Click subcommand group added to
the existing `eaasp` SDK CLI. All three ship in 3 atomic commits with
0 regression on the v3.14.0 + v3.14.1 backend test surface (66 tests
→ 75 tests after the 9-CLI additions).

## Canonical sources

- `tools/eaasp-ecosystem/src/eaasp_ecosystem/ecosystem.py` — 10 FastAPI routes + `AuthenticatedPrincipal` + `EcosystemConfig`
- `tools/eaasp-ecosystem/src/eaasp_ecosystem/ontology.py` — `OntologyService.derive_taxonomy / list_taxonomy / resolve_link / json_schema`
- `tools/eaasp-ecosystem/src/eaasp_ecosystem/marketplace.py` — `SkillMarketplace.submit_skill / promote_skill / list_skills / skill_stats / submission_audit / json_schema`
- `sdk/python/src/eaasp/client/skill_registry.py` — 49-line `SkillRegistryClient` thin wrapper (the reference pattern for the new client)
- `tools/eaasp-l5-cowork/src/eaasp_l5_cowork/cli.py:99-115` — `_trace_async` online-path pattern (the reference for HTTP CLI)

## Tasks

### Task 1: `EaaspEcosystemClient` sync + async + 4 typed exceptions

Create `sdk/python/src/eaasp/client/ecosystem_client.py`. The client
extends the existing `eaasp` package alongside `skill_registry.py` and
`platform_client.py` — **NOT** a new `eaasp_sdk/` package (D-42 thin
client; the package is the single source of truth for parameter
shapes).

- Sync `EaaspEcosystemClient` with 10 public methods: `get_health` /
  `get_schema` / `derive_taxonomy` / `list_taxonomy` / `list_ontology_links`
  / `submit_skill` / `promote_skill` / `list_skills` / `skill_stats` /
  `submission_audit`.
- Async `AsyncEaaspEcosystemClient` mirroring the same surface.
- 4 typed exceptions: `EaaspEcosystemAuthError` (401) /
  `EaaspEcosystemACLDenied` (403) / `EaaspEcosystemTenantForbidden`
  (403 cross-tenant) / `EaaspEcosystemPromotionError` (400/404/502).
- `httpx.Client(trust_env=False)` per the project-wide Clash proxy
  gotcha.
- Empty `api_key` rejected at construction (raises
  `EaaspEcosystemAuthError`).

**Tests**: `sdk/python/tests/test_ecosystem_client.py` — 17 respx-mocked
tests covering success paths for all 10 methods + 5 error-mapping cases
(401 / 403 / 403-cross-tenant / 404 / 502) + 2 async mirror tests.

**Verify before commit**:
```bash
cd sdk/python && pip install -e ".[dev]" && python -m pytest tests/test_ecosystem_client.py -v
# expect: 17 passed
```

### Task 2: `eaasp-ecosystem marketplace {submit,promote,list,stats,audit}` CLI subcommands

Extend `tools/eaasp-ecosystem/src/eaasp_ecosystem/cli.py`. Add
`_add_marketplace_parser(sub)` with 5 subcommands. **All go through
HTTP** via `httpx.Client(trust_env=False, timeout=10.0)` (matches the
v3.13.2 L5 cowork trace online-path pattern). The CLI does NOT
instantiate `SkillMarketplace` in-process for writes — that would
create a guard-bypass class (per the v3.14.0 round-1 audit).

- `--api-key` flag (or `EAASP_ECOSYSTEM_API_KEY` env var)
- `--base-url` flag (or `EAASP_ECOSYSTEM_BASE_URL` env var, default `http://127.0.0.1:18087`)
- `--timeout` flag (default 10.0)
- HTTP status → CLI exit code mapping: 2xx → 0, 401/403 → 3, 400/404 → 2, 5xx → 4

**Also fix the latent `os.environ.get` NameError bug** at the original
03.14.0 ontology parser (line 116/126/135) by routing through
`os_environ_or(name, "")` which lazily imports `os` at call time.

**Tests**: `tools/eaasp-ecosystem/tests/test_cli_marketplace.py` — 9
respx-mocked tests covering all 5 subcommands + 1 subcommand-registered
parser-level smoke test.

**Verify before commit**:
```bash
cd tools/eaasp-ecosystem && python -m pytest -v
# expect: 66 existing + 9 new = 75 passed
```

### Task 3: `eaasp ecosystem {schema,ontology,marketplace}` Click subcommand

Add `sdk/python/src/eaasp/cli/ecosystem_cmd.py` (Click group, extends
existing `eaasp.cli`). Register the new subcommand in
`sdk/python/src/eaasp/cli/__main__.py`. **No new top-level package** —
per D-42, the SDK is a thin wrapper.

- 3 subcommand groups: `schema` (top-level), `ontology {derive,tree,links}`,
  `marketplace {submit,promote,list,stats,audit}`.
- Auth via `--api-key` flag or `EAASP_ECOSYSTEM_API_KEY` env var
  (Click's `envvar=...` parameter auto-resolves).
- Missing `api_key` exits 2 with a human-readable error message; HTTP
  401/403 exits 3; HTTP 4xx other exits 2; HTTP 5xx exits 4.

**Tests**: Add 6 tests to `sdk/python/tests/test_cli.py::TestEcosystemCmd`
using respx + Click's `CliRunner`. Covers: help lists subcommands,
schema returns full JSON-schema, ontology derive prints graph,
marketplace submit forwards JSON body, marketplace promote 403 ACL →
exit 3, missing api_key → exit 2.

**Verify before commit**:
```bash
cd sdk/python && pip install -e ".[dev,cli]" && python -m pytest tests/test_ecosystem_client.py tests/test_cli.py::TestEcosystemCmd -v
# expect: 17 + 6 = 23 passed
```
