## Independent Security Review

The review identified one confirmed HIGH compatibility issue: initially granting `ManageUsers` to Admin contradicted v3.8's owner-only policy and an existing regression test. Commit `9f19e28` restored the boundary while retaining the expanded operational Action domains.

The coordinator's CRITICAL registry-fanout concern was also verified: production enum, parser, role policy, and exhaustive tests landed synchronously (`3c05324` + `9f19e28`), so no test-only or metadata-only variants remain.

## Decisions Made

- Full-mode authorization is a global post-auth route gate using Axum `MatchedPath`; this guarantees complete coverage without making dozens of handler functions public or duplicating route construction.
- None/ApiKey requests carry no `JwtClaims`, so the catalog gate is an intentional no-op and existing semantics remain unchanged.
- Admin manages operational domains; Owner alone manages users and global config.
