# Phase 03.9.2 Plan — CI authorization auditor and regression closure

Implement a pure auditor over route entries that reports duplicates, invalid public entries, missing allowlist entries, and Actions no Role can exercise. Add self-test with a synthetic unprotected/invalid route and clear named report. Expose a standalone binary returning exit 1 on findings.

### Task 2: CI and Make integration

Add `make rbac-audit` and wire it into `.github/workflows/ci.yml` after workspace check and before tests. Do not add dependencies.

Test every catalog entry for at least one positive role and all non-Read entries for Viewer denial. Preserve v3.8 regression suites and run targeted build verification; do not run workspace full tests.

Update USER_GUIDE §12, create dated production-usability evidence and regenerated Role × Action reference table. Independently review auditor vacuity, CI ordering, process exit behavior, matrix accuracy, and security semantics; fix confirmed findings.

- CI runs auditor in required ordering.
- All nine phase requirements have traceable code, test, or documentation evidence.
