Append a new section §11 covering:

- §11.4 注销 (logout): `POST /api/v1/auth/logout` blacklists the token's `jti`; middleware consults blacklist on every Full-mode request.
- §11.5 RBAC matrix reference: table of `Role × Action` from `Role::can()` in `crates/grid-engine/src/auth/roles.rs:69`.

TOC entry for §11 added in §目录 list (line 9-30).

### Task 2: Operator env-var reference (DOC-02)

**File:** `docs/cli/USER_GUIDE.md` — §11.6 (sub-section)

Document the four env vars with their defaults and strict-mode behaviour:

- `GRID_AUTH_MODE` — overrides `auth.mode` in `config.yaml`. Accepted values: `none` / `api_key` (default) / `full`. Read at `crates/grid-server/src/config.rs:496`. **Note**: the original 03.8.1 plan listed this as `GRID_MODE` — verified against the live code and renamed for accuracy.
- `GRID_JWT_SECRET` — REQUIRED when `mode = full` (ADR-V2-028 strict-by-default). Minimum 32 bytes; `try_from_env()` rejects shorter. Read at `crates/grid-engine/src/auth/config.rs:159`.
- `GRID_TOKEN_TTL_SECS` — JWT lifetime in seconds. Default 86400 (24 h). Read at `crates/grid-server/src/state.rs:157`.
- `GRID_USERS_JSON` — bootstrap credential store. JSON array of `{user_id, tenant_id, email, password, role}`. Empty / missing → login disabled (server logs a warning; AuthMode::Full behaviour: parse failure → panic per ADR-V2-028). Read at `crates/grid-server/src/state.rs:135` and `crates/grid-engine/src/auth/user_store.rs:78`.

The exact env-var names were verified against the live code (`grep -rn "GRID_" crates/grid-server/src/config.rs crates/grid-server/src/state.rs crates/grid-engine/src/auth/`).
